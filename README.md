# PrepMate (Flutter + Node + MongoDB)

```
backend/       Express + MongoDB API (auth, applications, progress, Gemini proxy)
prepmate_app/  Flutter app (Android, iOS, web, Windows)
```

1. Backend: `cd backend`, fill `.env`, `npm install`, `npm run dev` (see `backend/README.md`).
2. App: `cd prepmate_app`, run `setup.ps1` (Windows) or `setup.sh`, then `flutter run` (see `prepmate_app/README.md`).
